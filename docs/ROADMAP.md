# Roadmap

## 0.1.x — Foundation

- [x] Deterministic issue triage suggestions.
- [x] Release notes from Conventional Commits.
- [x] PR review checklist generation.
- [x] Repository health report.
- [ ] GitHub Action wrapper.
- [ ] JSON and Markdown output modes.

## 0.2.x — Maintainer workflow automation

- [ ] GitHub REST API integration for public repositories.
- [ ] Stale issue detection with configurable thresholds.
- [ ] Config file: `.oss-maintainer-kit.yml`.
- [ ] Label policy validation.

## 0.3.x — AI-assisted maintainer mode

- [ ] Optional prompt templates for Codex-based review summaries.
- [ ] Security-sensitive diff summary mode.
- [ ] Human approval gates for all suggested actions.

## Long-term vision

Make routine open-source maintenance easier without removing human judgment. The tool should help maintainers spend less time on repetitive triage and more time on project direction, security, and community support.
