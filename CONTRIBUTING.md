# Contributing

Thank you for helping improve OSS Maintainer Kit.

## Good first contributions

- Improve triage keyword coverage.
- Add examples for real maintainer workflows.
- Add tests for release note edge cases.
- Improve documentation and translations.

## Development workflow

1. Fork the repository.
2. Create a branch: `git checkout -b fix/my-change`.
3. Run tests: `python -m unittest discover -s tests`.
4. Open a pull request using the PR template.

## Review expectations

- Keep changes small and easy to review.
- Add tests for behavior changes.
- Explain user impact in the PR description.
- Avoid adding heavy dependencies without an issue discussion.
